# Évaluation — DS2 Legal Knowledge & Retrieval

Ce dossier contient les **golden sets et les métriques propres à DS2**.
L'évaluation n'est pas un rôle séparé : chaque rôle évalue son propre domaine.

À remplir par Abd Mouhib Souri. Contenu attendu :
- les **golden sets** : des cas d'entrée et la sortie attendue, avec la source
  qui justifie la sortie attendue (règle « Citation ou Silence ») ;
- les **métriques** : leur définition, le script de calcul et les résultats
  datés.

L'organisation des sous-dossiers est libre ; documentez-la ici. Les données
de test partagées avec d'autres rôles vont plutôt dans `data/mock_cards/`
(préfixe `legal_retrieval_`).
